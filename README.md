One funny line, told cold: a therapy confession that goes quietly wrong when the plants start answering back. Pure Python stdlib; it writes the line to `entry.txt`.

> I told my therapist I talk to my plants. She asked if they answer back. I said only the cactus, and only in threats.

## Why this line

- **A real joke with two turns:** the setup sounds like an ordinary therapy confession, then the plants answer back — and then only the cactus does, and only in threats.
- **The punch lands last:** "threats" is the final word, so the laugh arrives suddenly on a cold read.
- **Economy:** 116 characters, three short sentences, nothing left to trim.
- **A fresh angle:** no knock-knock, no bar, no "walks into" setup — just a houseplant with a grudge.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`): 116 characters, one line, no trailing newline.
